## 🌟 Overview

**The Life of a Developer** is an immersive storytelling web experience built for the *Frontend Odyssey Hackathon*.

Instead of a traditional static website, this project presents a **cinematic journey** of a developer’s life — from curiosity to growth — using scroll-based animations, interactive elements, and modern UI design.

The goal is to make users *feel* the journey, not just read it.

---

## 🎬 Features

* 🎭 Cinematic Hero Section with staged animations
* 📜 Scroll-based storytelling (parallax + reveal effects)
* 💻 Realistic developer journey narrative
* ⚡ Smooth GSAP animations and transitions
* 🎨 Modern UI using Tailwind CSS
* 📱 Fully responsive across all devices
* 🧠 Emotion-driven storytelling design

---

## 🛠️ Tech Stack

* **Frontend:** React (Vite)
* **Styling:** Tailwind CSS
* **Animations:** GSAP
* **Deployment:** Vercel

---

## 🧠 Story Flow

1. **Hero** – Curiosity begins
2. **Learning** – First steps into coding
3. **Bug Struggles** – Debugging chaos
4. **Reality** – Deadlines & coffee
5. **Growth** – Becoming a developer

## 🎯 Design Approach

The design follows a **minimal dark theme** with cinematic transitions to create a premium feel.

Each section is crafted to represent a stage in a developer’s journey, using motion and interaction to enhance storytelling. The focus was on **emotion + relatability + smooth experience**.
